# VencordAutoRepair 0.4.1

- Repairs the NoiseToggle v3 Discord bridge after Vencord reinstalls or updates.
- The repaired bridge supports switching Discord between Krisp and None with NoiseToggle v0.1.19. It also accepts requests from older NoiseToggle builds.
- The repair replaces outdated bridge blocks without duplicating them. Existing auto-repair preferences carry over.

Download the Windows x64 installer or portable ZIP from [v0.4.1](https://github.com/Extrautior/VencordAutoRepair/releases/tag/v0.4.1).
